## 额外成员：拼车之前先看清规则

Netflix 的账号不能在“家庭”之外共享。家庭指的是主要住所内联网的那组设备。不在同一住所的人，只能以额外成员的方式加进来，没有别的合规路径。

额外成员的规则：

- 价格：**含广告 $7.99/月，不含广告 $9.99/月**，按每位计
- 名额：Standard 限 1 位，Premium 最多 2 位，含广告 Standard 一档不能加人
- 账号：额外成员有自己的账号和密码，但费用由邀请他的人付
- 通过第三方套餐或加购包订阅的，价格和额外成员资格可能不一样

如果只是想和爸妈或伴侣各看各的，先确认是不是同一住所。跨城、跨宿舍、异地读书这类情况，都要走额外成员。

## 哪些内容和功能会被档位卡住

含广告档不是“全部内容加广告”，是“大部分内容加广告”。部分片源在这个档位不可用，界面上会显示锁形图标，点进去看不了。介意这一点的话，$8.99 和省心之间得选一个。

4K Ultra HD + HDR 和 Netflix 空间音频只给 Premium。如果电视是 4K 面板，却订了 Standard，片源会以 1080p 输出，等于硬件白买。

下载台数按档位分：含广告 2 台、Standard 2 台、Premium 6 台。经常出差、要在手机和平板都存离线片的人，这个数字比同时观看台数更容易不够用。
